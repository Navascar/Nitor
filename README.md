# Nitor

Програма для керування RGB-прожекторами через DMX512.
Nitor надсилає DMX у USB-інтерфейс або в мережу. Це один файл `nitor.exe` без додаткових бібліотек і завантажень.

## Можливості

Програма працює з такими DMX-виходами:
- USB-DMX адаптери (з власним USB-протоколом або через COM-порт);
- Art-Net;
- sACN (E1.31);
- симулятор без обладнання.

Що вміє програма:
- Патч приладів: назва, DMX-адреса, профіль каналів. Кілька однакових прожекторів можна додати разом, і вони отримають послідовні адреси. Якщо адреси приладів перетинаються, програма попереджає.
- Загальні профілі каналів RGB, RGBW, Dim+RGB і RGB+Dim для невідомого приладу, якому потрібне лише базове керування кольором. Профілі зі стробом, UV, сегментами чи програмами обираються разом із моделлю приладу в бібліотеці й у меню профілів не з'являються. Власний профіль складається з ролей `r g b w a uv dim strobe zero full`.
- 13 кнопок статичних кольорів, серед них теплий, звичайний і холодний білий. На RGBW-приладах білі кольори використовують W-канал. Клік заливає кольором вибрані прилади (або всі, якщо нічого не вибрано) і зупиняє на них ефект. Гарячі клавіші `1`–`9`. Можна зберегти власний колір, видалити непотрібні або повернути стандартний набір.
- Кнопка «Очистити» у верхній панелі (або Delete чи 0) гасить вибрані прилади чи сегменти, а якщо нічого не вибрано, то все. Ефект на них зупиняється.
- Окремий колір для кожного сегмента LED-бару: клік по сегменту на плитці приладу. Якщо увімкнено «по сегментах», ефекти біжать уздовж бару.
- Клік вибирає прилад, Shift + клік додає до вибору ще прилади. Ctrl+A вибирає всі прилади, Ctrl+Z скасовує дію, Ctrl+Y повторює. Подвійний клік відкриває властивості приладу. Правий клік відкриває контекстне меню, і його вміст залежить від панелі: прилади, колір, статичні кольори, ефекти чи сцени.
- Для LED-бару з вбудованими програмами з'являється перемикач «Пресети / Колір».
- Клік по числу біля повзунка дозволяє вписати значення з клавіатури.
- Колірне коло, палітра, окремі слайдери R/G/B/W/Amber/UV, диммер і канал стробу. Показуються лише слайдери, які є у вибраних приладів.
- Майстер-диммер і Blackout (гаряча клавіша `B`). Під час Blackout усі канали дорівнюють 0.
- Коли приладів немає або все світло вимкнене, програма не відправляє кадри: після кількох порожніх кадрів, щоб прилади згасли, відправка стоїть, доки щось не ввімкнеться. Індикатор виходу тоді показує «Пауза, світло вимкнене».
- Кнопка «Спалах» (клавіша `F`): поки її тримають, вибрані прилади (або всі) світять повним білим на повну яскравість, без ефекту й незалежно від майстра. Blackout спалах перекриває. Будь-який статичний колір чи сцену теж можна «спалахнути»: затисніть Alt і тримайте кнопку кольору чи сцени. Щойно кнопку відпустили, все повертається як було.
- Групи приладів («Сцена», «Ліва сторона»…): виберіть прилади й натисніть «Група» над плитками. Клік по групі виділяє її прилади, Shift + клік додає їх до вибору. Прилад може бути в кількох групах. Правий клік по групі — замінити, перейменувати чи видалити її.
- Режим оператора (замок у верхній панелі) для волонтерів: лишаються сцени, статичні кольори, групи, майстер, «Очистити», «Спалах» і Blackout; патчу, налаштувань, ефектів і редагування немає. Після перезапуску програма відкривається знову в режимі оператора. Вийти можна з PIN (від 4 до 8 цифр, задається під час увімкнення) або, якщо PIN не задано, утримуючи кнопку «Вийти» 3 секунди. Забутий PIN скидає команда `nitor.exe --reset-pin` (спершу закрийте програму) або видалення налаштувань у вікні видалення програми.
- Якщо адаптер від'єднали (висмикнули USB), програма щосекунди пробує підключитися знову, а індикатор виходу показує, скільки триває розрив. Щойно адаптер повернувся, прилади одразу отримують поточний кадр; у журналі видно, коли зник зв'язок і скільки його не було.
- Кнопка «Строб» (клавіша `S`) вмикає апаратний строб на вибраних приладах або на всіх, якщо нічого не вибрано. Діє лише на прилади з каналом строба.
- Гарячі клавіші можна переглянути й перепризначити в «Налаштування → Гарячі клавіші».
- Ефекти: веселка, плавна зміна кольорів, біжучий вогонь, пульсація, стробоскоп, випадкові кольори, вогонь. Для ефекту задаються швидкість, розкид фази між приладами і власна палітра.
- «У такт музиці» в блоці ефектів: швидкість ефекту береться з темпу, а крок прив'язується до удару (стробоскоп, пульсація й випадкові кольори — на кожен удар, плавні ефекти — на такт із чотирьох ударів). Можна додати спалах яскравості на кожен удар. Удари програма бере зі звуку, що грає на комп'ютері (за замовчуванням), з мікрофона або лише з тапу: натискайте `T` чи кнопку «Тап» у такт. Звук слухається, лише поки працює такий ефект.
- MIDI-контролер («Налаштування → MIDI»): натисніть «Навчити» біля дії й потім кнопку чи повзунок на контролері. Прив'язати можна Blackout, «Очистити», «Спалах», тап, майстер, швидкість ефекту, статичні кольори, сцени й групи. Для одного з поширених контролерів із сіткою падів 8×8 є готовий профіль: пади світяться кольором дії. Поки прив'язок немає, програма MIDI-порти не відкриває.
- VirtualDJ («Налаштування → VirtualDJ»): увімкніть «Приймати з VirtualDJ», і VirtualDJ сам знайде Nitor у мережі (OS2L). Удари з VirtualDJ задають темп «у такт музиці», а кнопка VirtualDJ з назвою сцени викликає цю сцену.
- Розклад («Налаштування → Розклад»): сцена, «Очистити» чи Blackout у потрібний час або на сході чи заході сонця з поправкою в хвилинах, у вибрані дні тижня. Схід і захід рахуються для вибраного обласного центру або своїх координат. Розклад працює, поки Nitor відкритий (вікно можна згорнути). Там же — «Запускати Nitor разом із Windows».
- Сцени з плавним переходом (кросфейдом). Сцену можна зберегти разом з ефектом.
- Сцену можна зберегти у файл `.nitor` (кнопка біля сцени або її контекстне меню) і відкрити на іншому комп'ютері кнопкою «Відкрити з файлу». Прилади зіставляються за адресою й каналами. Прилад, якого на іншому комп'ютері ще немає, додається на ту саму адресу, якщо вона вільна. Відкриття сцени скасовується через Ctrl+Z.
- DMX-монітор на всі 512 каналів і превʼю кольору кожного прожектора наживо.

## Встановлення (Windows 10/11, 64-біт)

Завантажте [Nitor-Setup.exe](https://github.com/Navascar/Nitor/releases/latest/download/Nitor-Setup.exe) і запустіть його. Права адміністратора й інтернет не потрібні. Інсталятор не підписаний цифровим сертифікатом, тому Windows може показати «Windows захистила ваш ПК». У такому разі натисніть «Докладніше», а потім «Усе одно запустити».

Інсталятор копіює програму в `%LOCALAPPDATA%\Nitor`, додає ярлики Nitor на робочий стіл і в меню «Пуск» (кожен можна вимкнути) і реєструє програму в «Параметри → Програми», звідки її можна видалити.

Тихе встановлення: `Nitor-Setup.exe /S` (параметри `--no-desktop`, `--no-start-menu` прибирають відповідні ярлики).

Під час запуску програма перевіряє оновлення. Якщо нова версія є, замість програми відкривається невелике вікно зі списком змін, і програма не запускається, доки її не оновити. Вікно можна перетягнути за будь-яке місце. Без інтернету програма відкривається як зазвичай. Прожектори світять, поки вікно відкрите. Закриття вікна (хрестиком або Alt+F4) треба підтвердити, після чого програма гасить світло й повністю завершується. Якщо програма вже працює, друга не запускається: з'являється попередження з кнопкою «Перейти до Nitor», яка показує відкрите вікно.

Видалити програму можна в «Параметри → Програми → Nitor → Видалити» або запустивши `Uninstall.exe` у теці програми. У вікні видалення є два варіанти: «Лише програму» — сцени, прилади й налаштування залишаються й повернуться після повторного встановлення — або «Програму разом із даними», де можна вибрати, що саме видалити: сцени, прилади, власні профілі, статичні кольори чи налаштування.

## Оновлення

Програма перевіряє [GitHub Releases](https://github.com/Navascar/Nitor/releases) під час запуску і далі щогодини (без інтернету — кожні 10 хвилин). Якщо нова версія вийшла, поки програма працює, у верхній панелі з'являється кнопка «Оновити до …». Вона відкриває список змін і кнопку «Встановити оновлення». Програма завантажує новий `Nitor-Setup.exe`, тихо встановлює його й перезапускається. Налаштування, прилади й сцени зберігаються, а світло під час оновлення не гасне. Перевірити оновлення вручну можна в «Налаштування → Про програму».

## Швидкий старт

1. Відкрийте «Налаштування → DMX-вихід» і виберіть свій адаптер або мережевий протокол. USB-адаптер програма знаходить сама (кнопка «Знайти» шукає повторно). Індикатор зверху має стати зеленим.
2. Натисніть «Додати» в панелі «Прилади» і додайте свої прилади. Стартова адреса має збігатися з DIP-перемикачами або меню прожектора, а профіль — з його DMX-режимом (кількістю каналів).
3. Клікніть прилад, щоб вибрати його. Shift + клік додає до вибору ще прилади або сегменти. Після цього задайте колір або запустіть ефект.

## Підключення USB-адаптера

Адаптер, що працює через COM-порт, програма бачить одразу. Адаптеру з власним USB-протоколом (без COM-порту) у Windows потрібен драйвер WinUSB, який ставиться один раз:

1. Підключіть адаптер і завантажте Zadig: https://zadig.akeo.ie
2. Запустіть Zadig і виберіть у меню «Options → List All Devices».
3. Виберіть у списку свій адаптер.
4. Праворуч виберіть драйвер WinUSB і натисніть «Install Driver» або «Replace Driver».
5. Програма підхопить адаптер сама. Перевірити підключення можна командою `%LOCALAPPDATA%\Nitor\nitor.exe --check`.

### Типові проблеми

| Повідомлення | Що робити |
|---|---|
| Адаптер не знайдено | Перевірте кабель і порт. Для адаптера без COM-порту встановіть WinUSB через Zadig. |
| Пристрій знайдено, але відправка не вдалася | Встановлено не той драйвер. Замініть його на WinUSB у Zadig. |
| Прилади не реагують, хоча статус «працює» | Перевірте адресу й DMX-режим на прожекторі, кабель DMX і термінатор 120 Ом на останньому приладі. |

## Бібліотека приладів

Кнопка «Вибрати з бібліотеки» у вікні «Новий прилад» відкриває бібліотеку готових моделей (близько 1300 моделей з відкритих баз описів приладів). Виберіть модель і режим DMX, який стоїть на самому приладі. Режим можна змінити пізніше у властивостях приладу. Бібліотека вбудована в програму й працює без інтернету. Переглянути бібліотеку й додати з неї прилад можна також у «Налаштування → Бібліотека приладів». Бібліотека завжди відкривається на розділі «Усі моделі».

## Розробка

Потрібен Rust (stable). Код кросплатформний, але збирається й перевіряється лише для Windows.

```bash
cargo test --workspace                                  # усі тести
cargo run -p nitor -- --config /tmp/cfg.json            # програма з окремим файлом налаштувань
cargo run -p nitor -- --check                           # перевірити підключення адаптера
NITOR_APP_EXE=target/release/nitor.exe cargo build --release -p nitor-setup   # інсталятор із програмою
```

Структура:
- `crates/nitor-core` — рушій без інтерфейсу: прилади, профілі, ефекти, сцени, рендер DMX, виходи, бібліотека, `config.json`.
- `crates/nitor` — програма на egui: вікно, вікно запуску, автооновлення, інтеграція з Windows.
- `crates/nitor-ui` — дизайн-система (токени, кнопки, повзунки, іконки), спільна для програми й інсталятора.
- `crates/nitor-setup` — `Nitor-Setup.exe`: встановлення й видалення.
- `crates/nitor-library` — збирає бібліотеку приладів з локальних клонів двох відкритих баз описів приладів: `cargo run -p nitor-library -- --ofl <…/fixtures> --qlc <…/resources/fixtures>`.

Ліцензії даних бібліотеки — у [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
